# Quill（羽笔）

面向长文本创作的桌面写作工具：**沉浸式编辑 + 大纲层级 + 一键思维导图**。数据完全本地，每篇文档是一个纯 Markdown 文件，由 git 提供版本管理。

> **开发版**：功能已成形、可用于日常工作与创作，但接口与数据格式仍可能调整，不建议存放不可替代的唯一副本。安装包见 [Releases](../../releases)。

## 功能

### 编辑

| 能力 | 说明 |
|---|---|
| 沉浸式编辑 | 无工具栏遮挡，正文栏宽 720px（可调），大留白；支持亮色与暗色主题 |
| 大纲 | 行首 `- ` / `1. ` / `[] ` 即时转换；`Tab` 缩进、`Shift + Tab` 退回 |
| 大纲折叠 | 含子列表的条目左侧显示折叠标记；折叠状态随编辑位置映射，不会错位 |
| 块拖拽排序 | 拖拽行首手柄调整块顺序，可跨层级；拖拽过程显示落点指示线 |
| 斜杠命令 | 任意位置输入 `/` 唤起块类型菜单（11 种），支持过滤与键盘导航 |
| 专注模式 | 仅高亮当前段落，其余淡出至 26% |
| 打字机模式 | 光标锁定在视口固定位置，滚动平滑跟随 |
| 待办列表 | 可勾选、可嵌套；输入 `[] ` 直接生成 |
| 表格 | GFM 表格（通过斜杠菜单插入），增删行列即时生效；写入 `.md` 为标准 `\| a \| b \|` 语法 |
| 代码高亮 | 按语言着色，配色跟随当前主题 |
| 媒体插入 | 截图 `Ctrl + V` 粘贴、从资源管理器拖入，或通过 `/图片`、`/视频` 选择文件；媒体存入仓库 `assets/` 目录，`.md` 中为普通 `![](assets/xxx.png)` |
| 图片尺寸 | 选中图片后拖拽右下角手柄调整宽度（拖动时显示像素值），双击手柄恢复自适应。已调整的图片写为 `<img … width="420">`，未调整的保持纯 Markdown |
| 富文本 | 标题、粗体、斜体、行内代码、高亮、引用、代码块、分隔线 |

### 外观

字体、字号、行距、栏宽与中文排版参数集中在设置面板的「外观」分区，也可从右侧栏快速调整。

| 参数 | 说明 |
|---|---|
| 主题 | 6 套配色，决定颜色、圆角与阴影 |
| 正文字体 | 霞鹜文楷、Inter、系统字体等；本机未安装时从 CDN 按需加载字形 |
| 正文字号 | 14–24px |
| 行距 | 1.5–2.6 |
| 正文栏宽度 | 480–1200px |
| 首行缩进 | 顶格 / 1 字 / 2 字。仅作用于正文段落，标题、列表项、引用与表格内的段落不受影响 |
| 段落间距 | 0–1.6em |
| 字间距 | 0–0.06em |
| 两端对齐 | 中文正文启用后右侧齐平 |

除栏宽外，各参数均以 `em` 为单位，随字号联动，调整字号后无需重新设定。外观设置对正文、便签、桌面磁贴三处同步生效。

### 窗口与界面

四个边栏遵循两条规则：

| 位置 | 行为 |
|---|---|
| 上（标题栏）、下（状态栏）、左（文档栏） | 鼠标移动即展开；开始输入时自动收起，为正文让出空间 |
| 右（外观栏） | 鼠标靠近窗口右边缘时展开，不占用正文宽度 |

- 收起采用负外边距实现真实让位，不使用 `transform`
- 状态栏内的正文字宽度滑块在鼠标悬停时锁定位置，避免拖动时连动
- 阅读模式与禅模式下，左右边栏一并让位

### 阅读

| 能力 | 说明 |
|---|---|
| 阅读模式 | `F9` 切换为只读通读：收起侧栏、工具栏淡出、正文放宽；右下角保留退出控件 |
| 禅模式 | `F11` 进入全屏并隐藏标题栏、侧栏与状态栏；文档信息与标签默认收起，鼠标进入正文区域时浮现。通过其他方式退出全屏（`Win + ↓`、`Esc`）会同步退出禅模式 |
| 分栏阅读 | 按章节分栏排版，横向翻页；左侧章节列表可直接跳转 |
| 超大文档支持 | 见「大体量文档」 |

### 大体量文档

数百万字的文档无法整体载入编辑器：编辑器的文档模型会为每个块建立节点，量级过大时会出现不可用级别的延迟。Quill 对这类文档采用按章节读取的方案。

- **章节索引由 Rust 侧流式扫描生成**，仅返回标题与字节偏移，不通过 IPC 传输原文。实测 709 万字文档：目录生成约 466ms，返回数据约 76KB
- **正文按章节惰性读取**，单章通常为数千字，读取与解析约 167ms
- 打开此类文档时提供两个选项：**进入编辑器**（功能完整，但会有明显延迟）或**分栏阅读**（流畅，只读）
- 分栏阅读界面与普通文档使用同一组件，章节目录、分栏排版、翻页、批注均一致
- 阅读视图中提供「去编辑」入口，可随时切换到编辑器
- 章节识别支持以下标题形式：`第X章 / 节 / 回 / 卷 / 篇 / 部`（含 `第 1 章` 这类含空格写法）、`Chapter N`、`1. 标题` 形式的编号分节，以及「楔子 / 序章 / 终章 / 尾声 / 后记 / 番外 / 间幕 / 幕间 / 外传 / 作者的话」
- **按章节编辑**：阅读视图中可将当前章节提取为独立文档进行编辑；该文档记录来源区间与内容摘要，修改完成后可合并回原文档，合并前会校验原文区间未被改动

### AI 助手（可选）

三项能力，其中仅第一项默认关闭。

**① 行内续写（默认关闭）**：停止输入一段时间后，模型基于上下文生成一段灰色提示文本；`Tab` 接受，`Esc` 忽略。提示为编辑器装饰，不进入文档数据，因此忽略等同于未发生。`Alt + /` 可手动触发。

- 兼容 OpenAI 接口：DeepSeek、OpenAI、Ollama、LM Studio 及各类中转服务，填写地址、密钥与模型名即可
- 模型名可直接从接口获取：点击输入框右侧按钮可拉取该地址支持的模型列表（`GET /models`），也支持手动输入自定义名称

**② 选中文本改写**：润色、精简、扩写、纠错、调整语气、译英。结果以流式方式展示在浮动工具条中，点击「采纳」后才写入文档（走正常事务，`Ctrl + Z` 可撤销），不满意可重试。

**③ 文档问答** `Ctrl + Shift + A`：摘要、问题排查、大纲提取、标题拟定。结果可插入文末或复制。

- **API 密钥仅保存在本机配置目录**（`%APPDATA%\com.quill.write\ai.json`），不写入文档仓库
- 全部请求走 SSE 流式传输

续写功能设有成本限制（每次请求均产生费用）：

| 限制项 | 默认值 |
|---|---|
| 触发时机 | 停止输入 N 毫秒后（默认 800ms，可调 300–2500） |
| 触发条件 | 光标前至少 6 个字、无选中内容、不处于输入法组词状态 |
| 去重 | 相同前缀不重复请求 |
| 生成长度 | 默认 160 tokens |
| 上下文 | 光标前最多 1500 字 + 文档标题 |

#### 可调参数

「设置 → AI 助手」中可调整三项长度、创意度与附加要求，修改后即时生效。

| 参数 | 默认 | 范围 | 作用 |
|---|---|---|---|
| 续写长度 | 160 | 64–512 | 行内续写的单次生成量 |
| 改写长度 | 2400 | 256–8192 | 选中文本改写的上限 |
| 回答长度 | 2000 | 256–8192 | 文档问答的上限 |
| 创意度 | 0.70 | 0–1.5 | 数值越低输出越稳定，越高越发散 |
| 附加写作要求 | 空 | — | 追加到三条系统提示词末尾 |

长度按 token 计算，中文约为一字一 token。回复触及上限时接口返回 `finish_reason: length`，界面据此提示「结果可能未完成」并指出需要调整的参数。

### 思维导图

- 大纲一键转为导图，使用 d3-hierarchy 计算布局，自绘 SVG 与贝塞尔连线
- 按文档结构分层：H1/H2/H3 为分支，列表项挂载到对应标题下；标题节点加重描边，正文段落淡显
- 连线生长动画与节点淡入
- 滚轮缩放（跟随鼠标位置）、拖动平移
- 点击节点跳回正文对应位置
- 导出 PNG（2 倍图）与矢量 SVG

### 数据与版本

- **一篇文章对应一个纯 Markdown 文件**，不使用私有数据库或专有格式
- **每次保存自动产生一次 git 提交**，提交信息为 `更新《标题》`；标题变更走 rename，历史连续
- 版本历史抽屉：列出提交、预览旧版本内容、一键回滚；回滚操作本身也产生一次提交
- 仓库默认位于 `%USERPROFILE%\Documents\Quill`，点击标题栏文件夹图标可用资源管理器打开
- 导出格式：Markdown、HTML（单文件）、PDF、JSON
- **PDF 导出通过系统打印**：在打印对话框中选择「Microsoft Print to PDF」。输出为矢量文本，中文清晰且可选中复制
- **从文件夹批量导入 Markdown**：选择文件夹后整批导入（适用于 Obsidian、Notion 等工具的导出结果）；重名文件自动添加序号，整批仅产生一次提交
- **复制为富文本**：带格式复制，粘贴到公众号编辑器或 Word 时保留标题、列表与表格
- 元数据（星标、标签、批注）存于 `.quill-meta.json`，统计存于 `.quill-stats.json`，均纳入 git 版本管理

### Markdown 支持范围

目标：**Markdown 文件经 Quill 编辑后，内容不得丢失**。逐项实测见 `verify-md-syntax.mjs`，共 72 项：60 项字节级无损，12 项规范化为等价写法，**0 项丢失**。

**完整支持，往返一致：**

标题 H1–H6、段落、引用与嵌套引用、无序/有序/任务列表与嵌套、代码块（含语言高亮；内容含围栏时自动加长围栏）、GFM 表格、分隔线、链接、图片（可带宽度）、视频、粗体/斜体/删除线/行内代码/高亮、硬换行、双链 `[[ ]]`、YAML frontmatter（原样保留于文件头）。

**可读取，保存时规范化为等价写法：**

| 输入 | 保存为 |
|---|---|
| `* 项目` 或 `+ 项目` | `- 项目` |
| `1) 第一` | `1. 第一` |
| `***` 分隔线 | `---` |
| `_斜体_` | `*斜体*` |
| `- [X]` | `- [x]` |
| Setext 标题 | ATX 标题 `# …` |
| 四空格缩进代码块 | 围栏代码块 |
| 标题紧邻正文 | 中间补一个空行 |

以上均为等价写法，内容与语义不变，且仅转换一次，后续保存不再变动。

**作为普通文本保留，不渲染：** 脚注、定义列表、HTML 标签、LaTeX 公式、单波浪线删除线。内容不会丢失，往返后仍为原样字面文本。

**已知差异：** 列表项内嵌的代码块，保存后会从列表项中提出成为独立块。内容与缩进保留，但不再挂载于该列表项下。

### 桌面集成

- Tauri 2 桌面壳（非 Electron，安装包与内存占用更小）
- **系统托盘常驻**：左键点击图标打开主窗口；右键菜单包含「记一笔」「打开 Quill」「立即同步」「退出」
- **关闭窗口时收进托盘**（默认启用）：主进程保持运行，`Ctrl + Space` 快捷便签不随窗口失效；可在设置中切换为「关闭即退出」
- **开机自启**（可选）：登录后在托盘待命
- **全局快捷键** `Ctrl + Shift + Space`：在任意位置显示或隐藏窗口
- **快捷便签** `Ctrl + Space`：唤出置顶小窗，回车保存至「收件箱」
- **桌面磁贴**：将指定文档固定在屏幕上（置顶、无边框），可随时查阅与一键复制全文
- **定时自动同步**（可选）：默认每 30 分钟一次，退出前补充一次；失败或冲突时提示，不静默忽略。未配置远程仓库时不启用
- 深色窗口背景，避免启动时白屏闪烁
- 提示系统：Toast 通知（保存失败、回滚完成、导出完成、模式切换）

## 发版

推送版本 tag 即自动发布 Release，无需手动打包上传：

```powershell
git tag v0.2.0
git push origin v0.2.0
```

`.github/workflows/release.yml` 在 windows-latest 上执行：

1. 从 tag 解析版本号并同步至 `package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`（版本号以 tag 为唯一来源）
2. 执行门禁：`pnpm typecheck` 与 `node test-core.mjs`
3. 执行 `pnpm tauri build`，产出 NSIS 安装包与免安装可执行文件，统一重命名为英文
4. 对比上一个 tag 生成更新说明，发布 Release

规则：

- tag 带后缀（`v0.2.0-beta.1`）→ 标记为 **pre-release**
- 不带后缀（`v0.2.0`）→ 正式版
- 补发或重发：在 Actions 页面手动触发 Release 工作流并填写 tag 名（tag 不存在时基于当前分支创建）

## 自动更新

应用启动 8 秒后静默检查更新，有可用版本时提示；也可在「设置 → 关于」中手动检查、下载与安装，安装完成后自动重启。

**更新包使用 minisign 签名**：公钥写在 `src-tauri/tauri.conf.json`，私钥仅存于 CI 的 GitHub Secrets（`TAURI_SIGNING_PRIVATE_KEY` / `_PASSWORD`）。验签失败时拒绝安装。

发布时 CI 会执行：`pnpm tauri build` 产出 NSIS 安装包 `Quill_<版本>_x64-setup.exe`，Tauri 对安装包本体签名（生成 `.exe.sig`），同时生成 `latest.json` 一并上传至 Release。客户端读取的地址为：

```
https://github.com/<owner>/<repo>/releases/latest/download/latest.json
```

> **仅正式版生效**：带 `-` 后缀的 pre-release 不会成为 `latest`，因此开发版不会自动推送给用户。

⚠️ **私钥位于 `%USERPROFILE%\.tauri\quill-updater.key`**：私钥丢失后将无法再签发更新包（只能更换公钥并重新发布，旧版本收不到更新）。请与密码一同备份。

## 验收

全部通过 CDP 驱动无头 Edge 执行真实断言。


## 设计决策

- **编辑器内核采用 Tiptap（ProseMirror）**：中文输入法、撤销栈与粘贴过滤由成熟实现承担。
- **Markdown 为唯一真相源**：序列化器与反序列化器均为手写且严格对称，`.md` 文件保持可读、git diff 友好，且不引入运行时依赖。
- **存储层抽象**：`DocStorage` 接口隔离「浏览器 IndexedDB」与「文件 + git」两套实现，上层无需区分。
- **git 使用系统 CLI 而非 libgit2**：行为与手动执行 `git log` 完全一致，便于排查；同时免除一套 C 构建链。
- **折叠状态以位置集合表示**：通过事务位置映射，在上方编辑时折叠状态不会错位，也不必将界面状态写入文档。
- **导图自绘 SVG**：d3-hierarchy 仅负责布局计算，渲染、交互与导出完全自主控制。
- **大文档章节索引由 Rust 侧生成**：IPC 返回值经过 JSON 序列化，传输数 MB 原文的代价过高；流式扫描仅返回标题与偏移，正文按章节惰性读取。
- **四个边栏遵循统一规则**：上、下、左三个边栏共用同一收放状态，右栏独立按鼠标位置触发。收起采用负外边距而非 `transform`，以确保真实让位。
- **零运行时后端**：不依赖任何服务端，完全本地运行。

## 已知事项

- 生产构建的 JS 单包约 674 kB（gzip 213 kB，主要为 Tiptap / ProseMirror）。可进一步做代码分割，将导图模块按需加载。
- 回收站内的文件同样纳入 git 版本管理（可恢复性的代价）；彻底删除后仍可从历史中找回。
- 拖拽落点指示线在自动化环境下无法验证（合成 DragEvent 不触发原生拖拽），需在真机确认。
- 首次构建需要 Rust 工具链与 MSVC 生成工具，一键脚本位于仓库根目录 `../setup-tauri-env.ps1`。
